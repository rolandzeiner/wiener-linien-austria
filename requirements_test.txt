# Test/lint dependencies. PHACC governs the whole test stack; this file
# declares only what PHACC does NOT pin.
#
# THE RULE — never declare anything PHACC pins with `==`. As of 0.13.361
# that covers pytest, pytest-asyncio, pytest-cov, pytest-timeout, syrupy
# and freezegun. A floor for any of them has exactly one candidate to
# resolve against, so it either matches (dead weight) or contradicts it
# (unresolvable). The three that used to sit here resolved to
# byte-identical versions once removed — verified against a clean 3.14
# venv, 2026-09-07. Consequence: pytest, syrupy and freezegun are
# imported directly by tests/ while arriving purely as transitives.
#
# ACCEPTED RISK — if PHACC ever loosened a pin to `>=`, a transitive minor
# could land unreviewed. Re-add a floor only with a named upstream change.
#
# PHACC tracks HA core including betas, so a patch bump can land on a beta
# and break lint (mypy --strict is the usual casualty) with no runtime
# fault. Fix with a temporary exact `==` pin carrying its removal
# condition — never by widening the range.
#
# PHACC 0.13.361 wraps HA core 2026.9.0b4 and needs Python >=3.14; CI
# tracks 3.14 in lockstep (validate.yml, tests job).
pytest-homeassistant-custom-component>=0.13.361,<0.14
